# Responsible Use / Disclosure

This file records the review-stage responsibility and disclosure check for Phase 5.

Use it to note whether the draft, review package, or submission context needs explicit disclosure, oversight, ethics handling, or withdrawal conditions.

## Suggested fields

- `round`
- `draft_or_submission`
- `ai_generated_content_disclosure`
- `human_oversight_summary`
- `ethics_or_approval_needed`
- `venue_or_audience`
- `withdrawal_or_nonpublication_rule`
- `risk_note`
- `status`

- `needs_approval`

## Usage notes

- Use this to make responsible-use expectations explicit before review actions are finalized.
- Capture any human approval, venue disclosure, or withdrawal protocol that affects the review cycle.
- Keep it separate from the review score ledger so ethics and disclosure do not get buried inside quality scoring.
