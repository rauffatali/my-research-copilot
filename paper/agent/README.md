# Paper Agent Artifacts

This directory stores agent-generated manuscript-support and review artifacts.

Examples include:

- claim audits
- review rounds
- revision plans
- response-to-reviewers drafts
- citation support notes
- figure support notes
- review score notes
- responsible use disclosure notes
- manuscript support notes

These files support the paper workflow but are separate from the main manuscript sources.

## Common templates

- `claim_support.md`
- `section_notes.md`
- `style_notes.md`
- `citation_support.md`
- `figure_support.md`
- `review_score_ledger.md`
- `responsible_use_disclosure.md`
- `review_context.md`
- `review_method.md`
- `review_domain.md`
- `review_hybrid.md`
- `review_meta.md`
- `revision_plan.md`
- `response_to_reviewers_draft.md`
- `claim_audit.md`
- `review_notes.md`

Use these as the durable handoff files for Phases 4 and 5.

For Phase 5, prepare `review_context.md` first so the reviewer-specific files can reuse the same summary, claim map, baseline context, and question engine.

Before using these templates on a new thread or when the workflow flow is unclear, consult `.agents/skills/workflow-manager/references/example_workflow.md`.
