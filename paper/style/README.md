# Style Samples and Templates

This directory contains sample and template assets for style bootstrapping and manuscript tone adaptation.

Files here are workflow examples and templates, not scientific evidence.

## Contents

- `prior_paper_reference.pdf` - placeholder PDF template for style-bootstrapping workflow
- `prior_paper_style.md` - template style guide used for style adaptation

Use these files only to extract or apply writing style traits. Do not treat them as manuscript evidence or as sources for claims, results, or citations.
