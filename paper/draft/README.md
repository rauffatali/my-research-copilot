# Manuscript Draft Staging

`paper/draft/` is provisional staging space for semantic or scientific-risk manuscript writing slices. It is separate from integrated or final manuscript sources.

It may contain a bounded slice such as:

- one sentence;
- one paragraph;
- several paragraphs;
- a transition;
- a subsection;
- multiple subsections;
- a complete section;
- a table or figure narrative; or
- another clearly bounded revision.

The layout does not require one file per section. A project may use one slice per file, multiple related slices per file, or another clear slice-oriented layout, provided that provenance, review state, and acceptance state remain understandable.

All candidate and resolved prose in this directory remains provisional until accepted. Acceptance is separate from protected integration into the project-local main manuscript target.

## Evidence-state rule

For a writing slice that depends on incomplete or changeable evidence, record the relevant `evidence_state` in the writing brief, a linked `paper/agent/` support artifact, or another clearly linked internal note. These internal labels guide drafting and review; they do not need to appear in polished manuscript sentences.

TODO tables, empty result cells, planned figures, and placeholder prose are `placeholder_only` until actual evidence replaces them. If a real run or raw result exists but has not completed the required Phase 3 consolidation, use `result_pending` instead. Neither state supports a final scientific finding by itself.
