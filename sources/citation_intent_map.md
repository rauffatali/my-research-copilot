# Citation Intent Map

## Purpose

This file maps citation candidates to the role they may play in the project or manuscript.

A citation should have an intent before it is used in paper prose.

This file does not replace BibTeX or citation metadata cleanup.

## Rules

- Do not cite a paper only because it was found by lookup.
- Do not cite a source for a claim it does not directly support.
- Do not use a citation as evidence until the relevant paper card or source artifact supports the intended use.
- Use citation-management for BibTeX, DOI, reference metadata, and formatting hygiene.
- Use claim-auditor before final manuscript claims.
