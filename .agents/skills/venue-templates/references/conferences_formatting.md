# Conference Formatting Reference

This reference supports the `venue-templates` skill.

Use it when preparing conference, workshop, symposium, or camera-ready submissions.

For current venue requirements, always verify the official conference website, template, call for papers, and submission system.

---

## 1. Purpose

Conference formatting guidance helps ensure that a manuscript follows the required structure, length, anonymization, template, and submission constraints.

This reference is a starting point, not an authoritative source.

Do not assume local notes are current for the present submission cycle.

---

## 2. Common Conference Requirements

Check:

- paper type: full, short, workshop, demo, dataset, benchmark, position, poster;
- page limit;
- reference-page policy;
- appendix/supplement policy;
- anonymization;
- font size;
- margins;
- column format;
- abstract length;
- title/author block rules;
- figure/table placement;
- line numbering;
- checklist or ethics statement;
- data/code availability statement;
- supplementary file rules;
- camera-ready differences.

---

## 3. Review vs Camera-Ready

### Review Submission

Usually check:

- double-blind anonymization;
- no acknowledgments;
- no author-identifying links;
- anonymous supplementary material;
- page limit;
- checklist requirements.

### Camera-Ready

Usually check:

- author names and affiliations;
- acknowledgments restored;
- final page limits;
- copyright block;
- final PDF compliance;
- supplementary packaging;
- reproducibility statements.

Do not apply camera-ready author information to anonymous submissions.

---

## 4. AI/ML/CV Conference Checks

For AI/ML/CV venues, also check:

- reproducibility checklist;
- ethics or societal impact statement;
- limitations section;
- code/data policy;
- benchmark policy;
- supplementary material policy;
- artifact appendix rules;
- official template version;
- whether references count toward page limit.

Common venues:

- NeurIPS;
- ICML;
- ICLR;
- CVPR;
- ICCV;
- ECCV;
- WACV;
- AAAI;
- IJCAI;
- ACL/EMNLP/NAACL for NLP work.

---

## 5. Template Use

Use official templates when available.

If using local assets, mark:

```text
TODO: verify this local template against the current official venue template.
```

Do not modify:

- margins;
- fonts;
- spacing;
- bibliography style;
- copyright block;
- required metadata fields;

unless the venue explicitly permits it.
