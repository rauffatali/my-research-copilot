# Nature / Science Style Reference

This reference supports the `venue-templates` skill for Nature-family, Science-family, and similarly selective journals.

Always verify the current journal-specific author instructions.

---

## 1. Scope

Use when targeting or imitating the structural expectations of:

- Nature;
- Nature portfolio journals;
- Science;
- Science Advances;
- similar high-impact interdisciplinary journals.

This file is not a substitute for official journal instructions.

---

## 2. Common Style Features

These venues often emphasize:

- broad significance;
- concise framing;
- strong but carefully supported claims;
- clear problem motivation;
- compact methods summary in main text;
- detailed methods/supplement as needed;
- high-quality figures;
- explicit limitations when appropriate.

Do not inflate claims to match perceived prestige.

Use `claim-auditor`.

---

## 3. Formatting Checks

Check journal-specific rules for:

- article type;
- title length;
- abstract format;
- display item limits;
- main text word limit;
- methods placement;
- references limit/style;
- data availability;
- code availability;
- competing interests;
- author contributions;
- supplementary information;
- figure format and resolution.

---

## 4. Abstract and Significance

A strong abstract should be concise and evidence-bound.

Avoid:

- broad hype;
- unsupported “first” claims;
- missing result evidence;
- overstated real-world impact.

Use `scientific-writing` for drafting and `claim-auditor` for final claim support.

---

## 5. Figure Expectations

Figures often carry much of the argument.

Venue Templates may check:

- number of display items;
- figure size;
- panel labels;
- resolution;
- caption style;
- supplementary figure placement.

Use `scientific-schematics` for technical figure creation when needed.

Do not generate figures by default.

---

## 6. Style Boundary

This reference can help align structure and formatting, but it should not:

- make the paper sound more important than it is;
- invent broad impact;
- change technical meaning;
- hide limitations;
- invent figures or results.

---

## 7. Checklist

- [ ] Exact journal identified.
- [ ] Article type identified.
- [ ] Official instructions verified.
- [ ] Title/abstract limits checked.
- [ ] Display item limit checked.
- [ ] Methods/supplement rules checked.
- [ ] Data/code availability rules checked.
- [ ] Reference style checked.
- [ ] Claims audited.
- [ ] Figures routed to correct visual skill if needed.

---

## Final Reminder

High-impact style does not justify high-impact overclaiming.

Evidence discipline comes first.
