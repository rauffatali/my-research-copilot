# ML / AI / CV Conference Style Reference

This reference supports the `venue-templates` skill for machine learning, artificial intelligence, and computer vision conference submissions.

Always verify current official instructions for the specific venue and submission year.

---

## 1. Scope

Use for venues such as:

- NeurIPS;
- ICML;
- ICLR;
- CVPR;
- ICCV;
- ECCV;
- WACV;
- AAAI;
- IJCAI;
- AISTATS;
- UAI;
- ACL/EMNLP/NAACL when NLP-focused.

---

## 2. Common ML/CV Requirements

Check:

- official LaTeX template;
- paper length;
- references included/excluded from page limit;
- appendix/supplement policy;
- review anonymization;
- author response/rebuttal rules;
- ethics statement;
- limitations section;
- reproducibility checklist;
- code/data availability statement;
- broader impact or societal impact statement;
- supplementary material file limits;
- camera-ready formatting.

---

## 3. AI/CV Paper Structure

A common AI/CV paper structure:

```text
Abstract
Introduction
Related Work
Method
Experiments
Results and Analysis
Limitations
Conclusion
References
Appendix / Supplementary Material
```

But venue templates may differ.

Use `scientific-writing` for prose.

Use `venue-templates` only for structural/format constraints.

---

## 4. CVPR / ICCV / ECCV Style Considerations

Common checks:

- official CVF/IEEE template;
- page limit for main paper;
- references excluded from page limit, depending on venue/year;
- supplementary material format;
- double-blind rules;
- author names removed during review;
- line numbers in review mode;
- final camera-ready author block;
- figure/table readability in two-column layout.

Always verify the current CVF instructions.

---

## 5. NeurIPS / ICML / ICLR Style Considerations

Common checks:

- official style file;
- page limit;
- checklist requirements;
- ethics/societal impact requirements;
- anonymization;
- appendix/supplement policy;
- final/camera-ready differences;
- author response constraints.

Always verify current instructions for the year.

---

## 6. Review Checklists

Many ML venues require checklists.

Venue Templates may identify and format checklist sections.

But checklist content should be grounded in evidence.

Use:

- `claim-auditor` for claim support;
- `citation-management` for references;
- `results-scaffold` for result table placeholders;
- `scientific-critical-thinking` for methodology and evaluation risks.

---

## 7. Common Formatting Risks

- using old style file;
- forgetting anonymous mode;
- keeping acknowledgments in review submission;
- references/page-limit misunderstanding;
- appendix included incorrectly;
- checklist missing;
- ethics statement missing;
- figures too small in two-column format;
- tables too wide;
- unsupported claims polished for submission.

---

- [ ] Venue and year identified.
- [ ] Official style file verified.
- [ ] Review or camera-ready mode selected.
- [ ] Page limit checked.
- [ ] Reference policy checked.
- [ ] Appendix/supplement policy checked.

---

## Final Reminder

ML/CV venue style files change.

Use local templates as starting points, not as final authority.
