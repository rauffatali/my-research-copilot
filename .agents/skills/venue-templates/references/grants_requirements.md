# Grant Requirements Reference

This reference supports the `venue-templates` skill for grant and funding proposal formatting.

Always verify the current solicitation, funder guide, and submission portal.

---

## 1. Scope

Use for:

- NSF proposals;
- NIH proposals;
- DOE proposals;
- DARPA proposals;
- foundation grants;
- institutional grants;
- fellowship applications;
- project concept notes.

Grant formatting is solicitation-specific.

---

## 2. Common Grant Components

Check whether the solicitation requires:

- project summary;
- specific aims;
- research strategy;
- significance;
- innovation;
- approach;
- broader impacts;
- intellectual merit;
- work plan;
- milestones;
- evaluation plan;
- management plan;
- budget justification;
- biosketch;
- facilities/resources;
- data management plan;
- mentoring plan;
- letters of support.

---

## 3. Formatting Checks

Check:

- page limits;
- margins;
- font size;
- line spacing;
- section order;
- file naming;
- required forms;
- appendix restrictions;
- biosketch format;
- budget format;
- deadline and submission system rules.

Do not rely on old templates.

---

## 4. Content Boundary

Venue Templates may identify required sections and formatting constraints.

Use:

- `scientific-writing` for proposal prose;
- `claim-auditor` for evidence-backed claims;
- `prior-style-adapter` for author style;
- `scientific-critical-thinking` for feasibility and aims critique;
- `scientific-schematics` for technical diagrams when needed.

Do not invent preliminary results, partnerships, budgets, or institutional commitments.

---

## 5. NSF Notes

Check current solicitation for:

- project summary structure;
- intellectual merit;
- broader impacts;
- project description page limit;
- references cited;
- biosketch;
- current and pending support;
- data management plan;
- mentoring plan if required.

---

## 6. NIH Notes

Check current FOA/instructions for:

- specific aims;
- research strategy;
- significance/innovation/approach;
- human subjects;
- vertebrate animals;
- authentication of key resources;
- biosketch;
- facilities;
- budget;
- data sharing.

Use medical/clinical guidance only when relevant.

---

## 7. Checklist

- [ ] Funder and solicitation identified.
- [ ] Official instructions verified.
- [ ] Required sections listed.
- [ ] Page limits checked.
- [ ] Font/margin rules checked.
- [ ] Budget/administrative requirements identified.
- [ ] Data management/sharing requirements checked.
- [ ] Claim/evidence needs routed to `claim-auditor`.
- [ ] Proposal prose routed to `scientific-writing`.

---

## Final Reminder

Grant requirements are solicitation-specific.

Always verify the current solicitation before final formatting.
