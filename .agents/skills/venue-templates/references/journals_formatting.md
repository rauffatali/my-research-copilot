# Journal Formatting Reference

This reference supports the `venue-templates` skill for journal manuscripts.

Always verify current author instructions from the journal website and publisher template.

---

## 1. Purpose

Journal formatting requirements vary by publisher, article type, and submission stage.

This reference helps identify what to check before formatting a manuscript.

---

## 2. Common Journal Requirements

Check:

- article type;
- word limit;
- abstract type and length;
- structured vs unstructured abstract;
- highlights;
- graphical abstract;
- keywords;
- section order;
- reference style;
- figure/table limits;
- supplementary material rules;
- data availability statement;
- code availability statement;
- ethics statement;
- conflict-of-interest statement;
- funding statement;
- author contribution statement;
- acknowledgments;
- cover letter requirements.

---

## 3. Initial Submission vs Final Formatting

Many journals allow flexible formatting at initial submission.

Check whether the journal requires:

- strict template at first submission;
- flexible format;
- final publisher template only after acceptance.

Do not over-format early if the venue allows flexible submission.

---

## 4. Article Type

Check whether the manuscript is:

- original research article;
- review;
- systematic review;
- short communication;
- technical note;
- methods paper;
- data paper;
- perspective/commentary;
- letter;
- registered report.

Article type affects structure and limits.

---

## 5. Abstract Requirements

Check:

- structured or unstructured;
- word count;
- required headings;
- no citations allowed;
- result value expectations;
- abbreviation rules.

Do not invent result values to satisfy an abstract.

Use `claim-auditor` before finalizing.

---

## 6. References and Bibliography

Journal requirements may specify:

- numbered style;
- author-year style;
- maximum number of references;
- DOI requirement;
- citation order;
- journal abbreviation style.

Use `citation-management` for reference integrity.

Venue Templates only identifies style requirements.

---

## 7. Figures and Tables

Check:

- figure file format;
- resolution;
- color policy;
- table placement;
- caption style;
- graphical abstract requirements;
- supplementary figure policy.

Use `scientific-schematics` or `generate-image` only if a visual artifact must be created.

Do not generate figures by default.

---

## 8. Reporting Statements

Check whether the journal requires:

- data availability;
- code availability;
- ethics approval;
- consent;
- competing interests;
- funding;
- author contributions;
- acknowledgments;
- AI tool disclosure.

Only include statements that are accurate and supported.

---

## 9. Checklist

- [ ] Journal and article type identified.
- [ ] Official author instructions verified.
- [ ] Template requirement checked.
- [ ] Abstract format checked.
- [ ] Word/page limits checked.
- [ ] Reference style checked.
- [ ] Figure/table requirements checked.
- [ ] Required statements checked.
- [ ] Supplementary material rules checked.
- [ ] Citation integrity routed to `citation-management`.
- [ ] Claim-heavy statements routed to `claim-auditor`.

---

## Final Reminder

Journal formatting is publisher- and article-type-specific.

Check the official author instructions before final submission.
