# NeurIPS / ML Conference Introduction Scaffold

Use this as a local scaffold for ML/AI conference-style introductions.

Verify current official venue instructions before submission.

## Typical Flow

1. Problem and motivation.
2. Prior work or current limitation.
3. Gap or failure mode.
4. Proposed approach.
5. Contributions.
6. Evidence summary.

## Scaffold

```text
[Problem] is important because [specific motivation with citation if external]. Existing approaches [brief prior-work pattern with citations], but [specific gap or limitation]. In this work, we [method/study focus]. Our contributions are: (i) [contribution 1], (ii) [contribution 2], and (iii) [evaluation or analysis]. We evaluate [method] on [dataset/protocol] and report [TODO: verified evidence summary].
```
