# Nature-Style Abstract Scaffold

Use as a local writing scaffold only.

Verify exact Nature-family journal instructions before use.

## Pattern

A concise abstract usually includes:

1. broad but specific context;
2. gap or limitation;
3. study/method focus;
4. evidence;
5. cautious implication.

## Scaffold

```text
[Specific problem context]. However, [specific unresolved limitation or gap with citation support]. Here we [study/method action] using [data/evidence]. We find that [TODO: verified result claim]. These results [careful implication], while [specific limitation] remains.
```

## Safety Notes

- Do not use broad prestige-style claims without evidence.
- Do not claim “first” unless closest-prior-work evidence is strong.
- Do not insert values until verified.
- Run claim-auditor before finalizing.
