# Tool Use Log

## Purpose

This file records important tool-assisted workflow actions.

Use this log when a tool, skill, MCP server, external lookup, code execution, retrieval step, or automated helper affects project direction, implementation, experiment design, evidence, claims, manuscript text, or review decisions.

Do not log trivial tool use that has no project consequence.

## Status

* Status: `draft`
* Allowed values: `draft`, `frozen`, `superseded`
* Project-specific tool uses recorded: `no`

## Tool Use Rule

A tool result is not durable workflow memory until it is reflected in the appropriate repository artifact.

This log records that a tool was used and points to the artifact where its useful output was saved.
