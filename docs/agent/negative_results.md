# Negative Results

## Purpose

This file records experiments, variants, ideas, or implementation attempts that failed, were inconclusive, or did not justify further work.

Negative results are important because they prevent repeated work and help explain why the final method or paper scope changed.

A negative result is not necessarily a bad result. It may be decision-changing evidence.
