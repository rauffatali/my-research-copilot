# Idea Archive

This file tracks candidate research directions considered during Phase 1.

Use one row per idea so the archive can be scanned, filtered, and compared later.

## Suggested fields

- `id`
- `title`
- `one_line_hypothesis`
- `why_it_matters`
- `baseline_or_reference`
- `novelty_risk`
- `expected_validation_signal`
- `priority_score`
- `status`
- `next_action`

## Suggested statuses

- `candidate`
- `selected`
- `deferred`
- `rejected`
- `archived`

## Usage notes

- Keep the archive compact and reviewable.
- Update the row when an idea is refined, selected, rejected, or superseded.
- Use it to preserve rejected or deferred directions that may still be useful later.
- Pair it with `research_direction.md` for the currently selected direction.
