# Evidence Review

## Purpose

This file records red-team review of interpreted results before they become manuscript claims.

Use it to check whether evidence actually supports the intended claims, whether alternative explanations remain, and whether results require additional experiments, caveats, or claim weakening.

## Status

- Status: `draft`
- Allowed values: `draft`, `completed`, `superseded`
- Evidence review recorded: `no`

## Evidence Review Rule

Run evidence review before:

- freezing Phase 3;
- drafting strong claims in Phase 4;
- using results in the abstract, introduction, or conclusion;
- claiming novelty, superiority, robustness, generalization, or mechanism;
- turning a surprising result into a main contribution.
